# AI-Based Fake Job & Internship Detection System

## Overview
An AI-powered system that analyzes jobs, internships, and links to identify potential fraud risks using risk scoring, trust indicators, and rule-based analysis.

## Features
- Fake Job Detection
- Internship Risk Detection
- Link Safety Analysis
- Risk Score & Confidence Percentage
- Company Trust Status
- User Authentication
- Scan History
- Favorites System
- PDF Report Export
- Safer Alternative Platforms
- Modern Responsive UI

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite
- Git & GitHub

## How to Run

1. Install requirements

```bash
pip install -r requirements.txt
```

2. Run application

```bash
python app.py
```

3. Open browser

```
http://127.0.0.1:5000
```
